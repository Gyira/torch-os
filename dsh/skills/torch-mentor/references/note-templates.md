# 笔记模板（与神对话 · 归档用）

frontmatter 由 `scripts/archive_note.py` 生成，**不要手写**。你只负责正文。

## 通用骨架

```markdown
> 摘要（≤40 字：关于什么 + 结论是什么）

## 背景

## 结论 / 判断

## 依据

## 下一步

## 相关

- [[另一篇笔记]]
```

## 摘要怎么写

- 好：`> 结论先行：换城市前先拿到新 offer，不裸辞。`
- 差：`> 关于换城市的一些想法`——没有结论，检索时等于没写。

摘要会被开场内核卡直接读出来，所以它必须能单独看懂。

## 按章节的骨架

### 反思 `reflection`（`00_人生路/02_反思复盘/01_反思`）

`> 摘要` → `## 发生了什么` → `## 我当时的判断` → `## 现在回看（对 / 错在哪）` → `## 下次怎么做`

### 心得 `insight`（`00_人生路/03_心得体会/01_生活心得` 等）

`> 摘要` → `## 场景` → `## 做法` → `## 为什么有效` → `## 边界（什么时候不适用）`

### 概念卡 `concept`（`03_知识库/04_概念卡片`）

`> 摘要` → `## 一句话定义` → `## 为什么重要` → `## 我的理解（用我自己的例子）` → `## 易混` → `## 相关`

### 方法 `method`（`03_知识库/05_方法库`）

`> 摘要` → `## 解决什么问题` → `## 步骤` → `## 我的验证记录` → `## 失效条件`

### 记忆与自传 `memory`（`01_自我档案/02_记忆与自传`）

`> 摘要` → `## 事实` → `## 当时感受` → `## 对我的影响`

### 项目计划 `plan`（`00_人生路/05_项目/01_项目计划`）

`> 摘要` → `## 目标` → `## 里程碑` → `## 风险` → `## 下一步`

## 命名与目录

- 文件名由 `archive_note.py` 生成：空格转下划线，禁用字符替换，重名自动 `-2`，绝不覆盖；
- 目录只用 `--list-chapters` 里的 key；
- 一次只写一个主题。两个主题就两篇，正文里互相 `[[双链]]`；
- 保留我的原话时，把原话放引用块 `>`，你的整理另起「AI 整理」小节，别混在一起。
