# 导航、本子文件管理与任务侧栏

本轮实现用户提出的四项界面改进。实际代码仓库为 `C:/Users/19814/Desktop/Torchos`。

## 使用方式

1. **设置中心 → 导航顺序**：拖动卡片到目标卡片的位置，松手保存并同步调整顶栏。取消拖动不改变顺序；箭头按钮可用于键盘及触屏调整；保留恢复默认。
2. **人生路 / 知识库**：右键本子或文档，或点卡片右上角 `•••`。支持多选、更改标题、删除；仅文档提供移动。Ctrl/⌘ 点击卡片可切换选择，工具栏可全选当前已加载页面。批量删除进入回收中心，不直接永久删除。
3. **顶部本子下拉**：悬停人生路、知识库可展开，方向键可打开并选择，Esc 收起；点主标题进入库页面，点箭头展开。下拉包含内置和自建本子，按最新页面数据刷新。
4. **任务侧栏**：主要导航文字 15px、分组 14px、计数 13px，行高至少 42px，桌面侧栏宽 236px；窄屏缩减宽度并沿用原有上下排列。

## 数据行为与边界

- **更改标题不是重命名路径**。文档更新 Markdown frontmatter 的 `title`；本子的显示标题保存在 `.torch-os/notebook-titles.json`，仍以原有 key 和目录识别。标题提示框会说明，避免影响既有链接和固定系统目录。
- 文档移动会实际移动 Markdown 文件，沿用现有同库移动接口与索引迁移；目标为同库中的普通可写本子 / 章节。不提供本子移动或跨库移动。
- 日记支持更改标题、删除和移出到普通本子；移动提示明确说明它会离开原日期的日记位置。习惯等系统记录仍在对应模块管理。
- 随笔、收件箱等默认本子维持原有删除保护。批量操作遇到保护项时逐项报告，不跳过后伪称全部成功。
- 每项文档操作在显示确认窗口之前读取版本；提交时校验版本。外部编辑导致 409 冲突时保留内容。
- 批处理逐项执行：报告成功数及每项失败原因，成功项退出选择，失败项保留选中；不以整体回滚覆盖并发编辑。
- 本子删除保留显示标题到回收清单，整本恢复时恢复标题及原目录、文件。新建同目录本子不会继承已删除本子的旧标题。
- 导航顺序复用现有个人偏好存储桥，权威副本随 `.torch-os/personal-data.json` 保存；本轮没有改动同步传输机制。

## 关键实现

- `frontend/settings.js`、`frontend/material.css`：导航拖动卡片和任务侧栏比例。
- `frontend/library-files.js`：右键/触屏菜单、选择工具栏、改标题及批量操作。
- `frontend/notebook-nav.js`、`frontend/app.js`：本子下拉、焦点/关闭行为及菜单互斥。
- `frontend/pillars.js`：本子标题投影、菜单入口、复用已载入总览的本子跳转。
- `backend/app/library_management.py`：标题配置持久化、文档范围与版本校验。
- `backend/app/notebooks.py`、`backend/app/notebook_recycle.py`：本子标题接口及回收恢复一致性。
