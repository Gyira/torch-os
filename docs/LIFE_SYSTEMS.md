# 生活运营系统（v1.0 P4）

> 生活运营 = 恋爱 / 健康 / 理财 / 家庭。v1.0 只把已有数据和 AI 角色接通；
> 健康、理财、家庭不做完整业务系统。

## 1. 总览

- 只读来源：健康系统的每日记录/身体档案/检验摘要（`02_生活运营/02_健康系统`）、
  `02_生活运营/02_财富与记账` 月度表；恋爱系统自己的只读摘要（不读原始聊天）；
  工作台未完成任务与今日习惯。
- AI 角色：
  - `life_assistant`（总览/建议）→ `08_生活建议`
  - `health_doctor`（健康报告/建议）→ `02_健康系统/00_健康报告`
  - `finance_advisor`（财务报告）→ `07_财务报告`
  - `love_master`（恋爱建议）→ `08_生活建议`
- 报告由用户确认后生成；建议里的任务/习惯只生成 `ai_proposals`，采纳后才创建。
- **不改**健康每日记录/财务月度表；**不**替恋爱系统发消息；**不**控制任何家庭设备。

## 2. 健康系统（2026-10-31 起）

- 原生二级分区：生活运营 →「健康系统」，与「恋爱系统」平级；详细设计见
  [`HEALTH_SYSTEM.md`](HEALTH_SYSTEM.md)。
- 数据：`02_生活运营/02_健康系统/`——`01_每日健康/YYYY-MM-DD.md`（睡眠/身体/体征/
  饮食/活动/心理/训练，frontmatter 结构化 + 正文可读摘要）、`02_身体档案`、
  `03_体检与检验`、`00_健康报告`。旧 `01_健康与体重/YYYY-MM.md` 只读兼容，不再写入。
- 能力：今日总览与六维健康指数、身体成分与体征、睡眠评分、餐次与宏量、步数与
  久坐、情绪/压力/正念、训练组记录与容量、检验参考区间与异常、30 天趋势、
  规则洞察（样本门槛 n≥5）、周报/月报。
- 私人医生：页面按钮打开角色抽屉（`advice`）；`POST /api/health/report`
  用 `report` 模式生成报告。上下文是只读摘要，不含每日正文；报告 `memory: false`。
- 未做：训练计划、体检报告 PDF/OCR、CSV 批量导入、进度照片、Web 提醒。
  这些不阻塞记录与报告；先以 Markdown 为权威。

## 3. 理财系统（当前能力）

- 数据：`02_生活运营/02_财富与记账/YYYY-MM.md` 月度表
  （日期/类型/金额/分类/账户/备注）。
- 仪表盘/汇总：`structured_notes.summary`；收入/支出/结余与主要分类由代码计算。
- 理财专家：`POST /api/ops/ai/report {domain:"finance", confirm:true}`；
  报告写 `07_财务报告`；不做投资建议、不推荐具体产品。
- 未做：账户余额、预算、负债、投资明细、账单导入；后续版本再做。

## 4. 家庭系统（占位）

- `02_生活运营/09_家庭与智能家居` 是占位章节；
- v1.0 只展示“后续版本”空状态，不发起任何设备/网络请求；
- 未来方向：家庭物资库存表、智能家居控制面板；需要单独的安全与权限设计，
  不在 v1.0 范围内。

## 5. 恋爱系统

- 现有 12 页 UI、导入/微信同步/分析/画像/日志/记忆/报告/值班/八字保持不变；
- 新增 `love_master` 只读建议：上下文只取最新分析摘要、项目基本信息，
  **不发送原始聊天消息**；
- 报告/建议写 `08_生活建议`，不覆盖恋爱系统自己的 `.torch-os/love/` 数据；
- 恋爱系统现有的独立 DeepSeek Key 直连保留，是 v1.0 唯一的过渡例外。

## 6. API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/ops/ai/overview` | 健康/财务/恋爱摘要、最近报告、未完成任务 |
| POST | `/api/ops/ai/report` | `{domain, confirm:true}`；生成并保存报告 |
| GET | `/api/ops/{dataset}/summary` | 既有只读月度汇总（health/finance；health 旧表只读兜底） |
| GET | `/api/ops/{dataset}/months/{month}` | 既有只读月度表 |

健康系统自己的记录/趋势/洞察/报告接口见 [`HEALTH_SYSTEM.md`](HEALTH_SYSTEM.md) 第 4 节。

## 7. 边界

- 报告是参考，不是诊断/投资建议；健康异常建议线下就医；
- 报告/建议 `memory: false`，不进入记忆候选，避免 AI 结论自我循环；
- AI 不可用时返回 409/503，原有月度表与仪表盘不受影响；
- 家庭占位页不包含任何设备控制代码。
