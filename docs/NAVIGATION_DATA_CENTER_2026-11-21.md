# 导航与数据中心整理（2026-11-21）

## 页面与入口

- 顶栏保留工作台、人生路、自我档案、生活运营、知识库、与神对话。导航排序从右侧齿轮打开，仍支持拖拽和键盘上下移动。
- 与神对话下拉增加 AI 角色与模型；独立页面复用原有编辑器及未保存离开确认。
- 自我档案下拉提供人生导师、八字系统。
- 工作台原晨晚报入口改为数据中心，旁边放回收中心；滴答同步设置位于任务侧栏回收站下方。
- 取消设置中心页面入口，删除帮助、关于、定时提醒页面内容。小组件只保留工作台“布置工作台”入口。

## 数据中心

概览展示 Markdown 文件数、本地备份数量及最近时间、数据库完整性；条形图展示文件与记忆的独立计数，不混用为空间占比。
四张操作卡打开备份恢复、数据导出、库与工作区、库结构迁移弹窗。表单移动而非复制，保留草稿、唯一 ID、原有操作校验；操作记录与自检位于页尾。
概览失败显示错误及刷新入口，不填造零值。宽屏与 390px 窄屏均检查横向溢出。

## 横幅与提醒

横幅非交互元素区域点击、焦点在横幅时 Enter/空格均打开数据看板；按钮各自保持独立行为。移除原双击编辑行为，避免一次双击同时打开两个弹窗。
收起/展开使用 320ms 高度动画，快速连续点击从当前显示高度接续，遵循减少动态效果偏好。
后台不再启动晨晚周报循环，也不再注册对应调度接口，能力标记为关闭，历史数据保留。已核对当前个人库身份并关闭运行中旧服务的三个提醒开关；新后台代码下次服务启动生效。
