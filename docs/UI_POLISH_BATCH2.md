# UI 打磨第二批：任务层次与设置抽屉

日期：2026-11-02。原生 JS/CSS；保留品牌、模块位置、导航、保存 API。未新增依赖或迁移数据。

## 诊断与实施

| 位置 | 原现象与影响 | 优先级 | 本批处理 |
| --- | --- | --- | --- |
| 任务添加上方 | 路径与兼容说明占据主要阅读路径 | P2 | 原生 details 渐进披露；只读模式/旧任务数量留在摘要中 |
| 任务列表 | 标题、分组、任务行间层次较弱；更多按钮只随悬停出现 | P2 | 标题 20px/1.4，头部间隔 16px，分组分隔线，行高至少 44px；键盘进入行时显示更多，触屏常显 |
| 恋爱设置抽屉 | aside 缺少模态约束与稳定回焦；背景仍可键盘进入 | P1 | 原生 dialog/showModal；打开聚焦关闭按钮；关闭回入口；背景不可交互；独立滚动 |
| 设置异步读取 | 关闭/重开后旧响应仍可回填 | P1 | 请求序号校验；关闭令旧请求失效；旧保存完成不会重新打开已关闭抽屉 |

## 交互习惯、收益与迁移

| 现状 → 建议（已实施） | 理由/收益 | 成本与风险 | 回退 |
| --- | --- | --- | --- |
| 常显路径 → 默认折叠辅助说明 | 把注意力留给任务和添加入口 | 查看路径多一次展开；只读提示不折叠 | 回退 index.html/time-module.js 对应片段 |
| 遮罩侧栏 → 原生模态侧栏 | 焦点与视觉范围一致；内层确认框关闭不会顺带触发全局 Esc 关闭设置 | 打开期间不能 Tab 到背景；符合现有遮罩表现。需在 Obsidian 宿主补验 | 成组回退 love.js、index.html、styles.css 的抽屉片段 |
| 紧密任务行 → 44px 最小行高 | 提高分组辨识和点击容错 | 同屏行数稍减；不提供新的布局模式或改变排序 | 回退第二批任务 CSS 块 |

## 状态与边界规格

| 组件 | 默认/hover/focus/active | 禁用/加载/错误/空/成功 |
| --- | --- | --- |
| 存储说明 | 默认折叠；悬停/按下背景反馈；全局可见焦点；Enter/Space 原生展开 | 无数据隐藏；只读信息常显在摘要；无需独立提交状态 |
| 任务行 | 主文字、辅助信息、分组分层；聚焦行内控件显示更多；触屏常显更多 | 延续首批加载/错误/空/成功逻辑；旧任务保持禁用 |
| 设置抽屉 | 关闭按钮初始聚焦；Esc、关闭按钮及完整遮罩点击退出；滚动时关闭入口保持可见 | 正文 aria-busy；保留原有加载、错误、空数据、保存提示；关闭废弃旧读取结果，不取消已发出的保存 |

- 动效：抽屉 220ms，位移 16px + opacity，缓动 cubic-bezier(.2,.8,.2,1)；摘要背景 150ms。沿用首批全局 reduced-motion 关闭规则。
- 响应式：抽屉最大 520px，小屏全宽，100dvh；长路径换行；内部滚动不带动背景。粗指针相关按钮/任务控件至少 44×44px。
- 未新增自动保存、自动重试或超时策略；沿用原 API 超时。关闭前的已提交写入仍由原业务处理。
- 目前为中文 LTR 产品，本批不宣称 RTL 支持。
