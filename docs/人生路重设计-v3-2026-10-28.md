# 人生路重设计 v3：一个输入口，一篇路

> 2026-10-28 · 用户定案：人生路右侧组件太多、不知道点哪个；目标与计划等"长久的东西"
> 不该住在"路"里；任务待办与组件数据统一放 `.torch`；**一个输入界面，AI 判别写的是什么**。

## 0. 一句话

人生路从 15 个章节、右栏一堆组件，收成**一个组件 + 一条时间线**：
你只管写，AI 负责判断这段是日记、反思还是心得，判断完给你确认，然后各归各位。

## 1. 现在为什么不好用

- **入口太多**：右侧挂了今日、7 天、习惯、目标、项目、复盘…… 每次来都要先做一次选择题；
- **混了两种东西**：「今天干了什么」是高频的，「年度目标 / 项目计划」是低频长久的，放在同一屏，
  高频的被低频的挤掉了；
- **两套数据**：任务在四库 Markdown，组件状态在 `.torch`，勾选、统计、备份各走各的；
- **分类靠你**：写之前先想"这算反思还是心得"，于是干脆不写。

## 2. 新的四库分工

| 库 | 管什么 | 判断标准 |
|---|---|---|
| **人生路** | 每天 / 经常发生的事 | 三个月后回看，它还在"过日子"这一层 |
| **自我档案** | 我是谁、我要去哪 | 目标、项目、原则、身份——**长久才成立** |
| **生活运营** | 身体、钱、证件、关系 | 有数字、有周期、要留痕 |
| **知识库** | 可复用的知识 | 换个人也能用 |

**人生路只剩 3 个章节**：

| 章节 | 内容 | 频率 |
|---|---|---|
| `01_日记` | 今天干了什么（AI 追踪 + 你补一句） | 每天 |
| `02_反思` | 哪里做得不够好、下次怎么改（**反思与复盘合并**，用 `scope: day/week/month` 区分，不再分工作/生活） | 有事才写 |
| `03_心得` | 偶尔心血来潮的体会（生活/工作/学习不再分目录，用 `tag` 区分） | 随时 |

**移出去的**：

- 目标（年/季/月）→ `01_自我档案/05_意义与目标`
- 目标、长期计划（含原来的"项目"笔记，如考研规划文档）→ `01_自我档案/05_意义与目标`；
  **不单设项目章节**（2026-10-28 定案：项目不要了）
- 习惯追踪、任务与待办 → `.torch`（不再是四库章节）
- 周复盘 / 月复盘 → 不再是目录，变成"反思"的一种 `scope`

## 3. 那一个组件

```text
┌──────────────────────────────────────────────┐
│ 今天 · 10月28日 周三                          │
│ 动了 7 篇笔记 · 1 件逾期 · 日记还没写          │
│ 提示：背单词逾期 6 天 ｜ 反思 11 天没记        │
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │ 今天想说什么…                              │ │
│ │ （可以写很长，一句也行）                    │ │
│ └──────────────────────────────────────────┘ │
│ [聊着写]                    [存下来]          │
├──────────────────────────────────────────────┤
│ 今天已记                                      │
│ · 日记  10:32  完成这周第一轮复习…            │
│ · 反思  14:05  值班那天不该硬扛…              │
└──────────────────────────────────────────────┘
```

下面直接接时间线（按天倒序），不再有第二个面板。

### 交互

1. **写**：输入框随便写，可以混着写「今天干了啥 + 我觉得哪里不对 + 一个体会」；
2. **聊**：点「聊着写」，同一个框变成对话，AI 一次问一句，聊完一样出卡片；
3. **存**：点「存下来」→ AI 把这段话拆成 1–3 张卡：

```text
┌ 日记 ─────────────────────────────┐
│ 今天完成第一轮复习，动了 7 篇笔记。   │
│                          [改成反思] │
└────────────────────────────────────┘
┌ 反思 ─────────────────────────────┐
│ 值班那天不该硬扛，下次先叫备班。      │
│                      [改成心得] [删] │
└────────────────────────────────────┘
```

4. **确认后落盘**：日记进当天文件；反思/心得各自新建一篇。
   分类永远可改——**AI 判别，你拍板**。

### 日记不再靠"写"

每天打开时，组件已经用系统的操作记录拼好了「今天干了什么」：
动过哪些笔记、完成了什么、习惯打没打卡、dsh 会话里聊了什么。
你只需要补一句"今天感觉如何"或者干脆不改，一键存。

## 4. AI 怎么判类

| 信号 | 判成 |
|---|---|
| 描述发生了什么、完成了什么、去了哪 | 日记 |
| 「不该 / 下次 / 其实 / 发现 / 教训 / 后悔」 | 反思 |
| 「明白 / 原来 / 意识到 / 学到 / 想通」 | 心得 |
| 有明确截止日、要别人配合、动词开头 | 任务（进 `.torch`，可一键转） |

规则先跑，模型只在**边界情况**上兜底（比如一段话里既有事实又有反思，就拆两张卡）。
判错的代价必须是零：分类 chip 永远可点。

## 5. 数据口径

一条规矩：**内容归四库，状态归 `.torch`。**

| 放哪 | 存什么 | 例子 |
|---|---|---|
| `.torch/tasks.json` | 任务、待办、截止日、完成态 | 背单词 / 10-22 / 未完成 |
| `.torch/habits.json` | 习惯定义、打卡 | 早起喝水 |
| `.torch/daily.json` | 每日必做勾选 | 今天勾了 2 个 |
| `.torch/journal/<day>.json` | 当天组件的草稿、分类结果 | 待确认的 3 张卡 |
| 四库 Markdown | 日记正文、反思、心得 | 最终成品 |

代价要说清楚：任务搬进 `.torch` 之后，**Obsidian 里就看不到任务了**。
补偿：每天自动导出 `任务（导出）.md` 到 `03_知识库/00_收件箱`，只读，不参与流程。

## 6. 迁移（四步，每步可回滚）

1. **备份**：整库复制到 `.torch-os/backups/vault-before-v3-<stamp>/`；
2. **搬长久的**：目标、项目 → 自我档案；反思/复盘合并、心得三合一（移动，不删）；
3. **搬状态的**：3 条任务笔记 → `.torch/tasks.json`，原文件移到 `_归档/任务笔记/`；
4. **换导航**：人生路只剩 3 章；旧章节 key 保留为只读兼容，不再出现在导航与卡片里。

每一步都先 `--dry-run` 出清单，你点头再执行。

## 7. 分期

| 期 | 内容 | 工期 | 验收 |
|---|---|---|---|
| P1 | 组件（盘点 + 输入 + 存下来 + 今日已记 + 时间线），先只接日记 | 2 天 | 打开人生路只需要看一个地方 |
| P2 | AI 判类 + 反思/心得落盘 + 分类可改 | 2 天 | 一段混写能拆成两张卡 |
| P3 | `.torch` 任务迁移 + 旧组件下线 | 2 天 | 任务在组件里能勾，Obsidian 有导出 |
| P4 | 章节迁移 + 导航收敛 | 1 天 | 人生路只剩 3 章 |

## 8. 不做什么

- 不做第二个入口（工作台只保留任务/日历，不再放日记入口）；
- 不在组件里堆分数、连续天数、成长曲线；
- 不自动落盘：**分类永远要你点一下**；
- 不删旧笔记，只移动和归档。

## 9. 已定（2026-10-28 深夜）

1. **项目不要了**：不设项目章节；原来的项目笔记（考研规划文档）并进
   `01_自我档案/05_意义与目标`。目标、计划、项目是一类东西——"我要去哪"。
2. **任务导出要**：每天一次 `任务（导出）.md` 进收件箱，只读，不参与流程。
3. 组件先接**日记 + 反思 + 心得**三类（并入上面的判类），不做"任务"判类——
   任务等搬进 `.torch` 之后单说，避免出现两套任务。

## 10. 已开工（2026-10-28）

`backend/app/journal_inbox.py` 已实现"一个输入口"的引擎：

- `POST /api/journal/inbox/classify`：一段话 → 最多 3 张卡（日记/反思/心得），
  带 `label`、`confidence`、`reason`（命中的词）、`target`（建议去向）；
- `POST /api/journal/inbox/save`：确认后落盘——日记并进当天笔记的「我想说的」，
  反思/心得在各自章节新建（`type`/`title`/`created`/`来源`/`tags`），重名自动加 `-2`；
- 只写今天、只写人生路；写前备份、只读库 409；分类不满意可改，`target` 由服务端重算，
  客户端不能指定路径。

实测一段混写（改组件 / 不该熬夜 / 原来规则更稳）被拆成 3 张卡，理由分别是
「今天·下午·跑了」「不该·其实」「原来」。

下一步：人生路页面换成「今天组件 + 时间线」，右栏旧卡片全下线。
