# 工作台材质与就地设置改造 · 2026-11-15

## 本次体验变化

Torch 自有工作台采用同一套表面层次：暖白陶瓷内容区、石墨暗色内容区、半透明导航、细边框和低对比阴影。保留薪火的暖色强调及各业务模块的识别色。宿主提供完整主题时，继续使用宿主颜色，不强制覆盖 Obsidian / dsh 的明暗方案。

“呼吸感”通过留白、标题与正文间距、减少同时展开的配置实现。没有给正文、表格或普通按钮添加持续漂浮、碰撞或跟随鼠标的形变。

- 工作台新增“布置工作台”“晨晚报与提醒”；任务和习惯各有“同步设置”。操作在当前页面弹出，结束后回到触发按钮，页面和滚动位置保留。
- 就地面板和设置页使用同一个真实表单。打开时搬入，关闭时归位，不复制 ID、不重复绑定保存逻辑。小组件开关立即生效；提醒、同步仍用原来的显式保存按钮。关闭不自动提交，已输入但未保存的内容在当前页面会话内保留。
- 读取配置期间禁止编辑；读取失败也不让用户把空默认值误当作最新配置保存，关闭后可以重试。
- 同步面板以清楚的开关行呈现日常选项；连接记录、高级参数折叠。首次连接时展开账号区，已配置账号默认收起。原删除确认、权限与后端校验保留。
- 设置页按日常偏好、数据维护、支持分组，修正“侧边栏菜单”等过时说明；备份、迁移仍留在全局设置。
- 小组件开关拥有具体可访问名称，重绘后保持键盘焦点。手机宽度下调整按钮间距、弹层尺寸，横幅工具不再遮盖引言。
- 首屏导师提醒预留位置；热力图预设颜色移入样式表，修复六处被 CSP 拦截的内联样式。

## 动效规则

| 场景 | 实现 | 中断与结束 |
| --- | --- | --- |
| 主导航、模块导航、任务栏、设置导航、恋爱导航 | 独立选中背景 FLIP 位移与轻微伸展，文字和点击区域不动 | 340 ms；伸展最多 9%；重复选择从当前绘制位置接续，最终追随已提交的选中状态 |
| 设置与已有弹层展开 | 透明度与 10 px 位移 | 240 ms；不等动画完成才接受输入 |
| 就地设置关闭 | 透明度与 8 px 位移 | 130 ms；Esc 和关闭按钮共用流程，原表单归位后恢复焦点 |
| 开关与按钮 | 开关滑块位移、按钮按下 0.98 缩放 | 180–220 ms；按钮不跟随鼠标移动 |
| 减少动态效果 | 系统媒体查询 | 取消导航动画、弹层直接开关、按钮与滑块保持静态 |

参数集中在 `frontend/material.css` 和 `frontend/material-motion.js`。动画只改变 transform / opacity；导航宽高只在选中项或尺寸变化时测量一次。使用 MutationObserver / ResizeObserver 合并到 requestAnimationFrame，没有常驻物理循环，也不延迟路由提交。导航仍保持原有 navigation / tab 语义。

原生 dialog 提供模态背景隔离；额外处理 Tab 首尾循环、Esc、焦点返回。读取期间保留可用的关闭按钮。不使用点击遮罩即关闭，避免密集表单操作误关。

## 实现位置

- `frontend/material.css`：统一材质、字体、间距、响应式、开关与弹层；加载在原业务样式之后。
- `frontend/material-motion.js`：导航背景动画、连续输入承接、尺寸重测与清理。
- `frontend/context-settings.js`：原表单挂载、草稿保留、异步读取状态、键盘与关闭行为。
- `frontend/index.html` / `app.js`：入口、设置分组、提醒占位、模块预加载。
- `frontend/dida-sync.js` / `inbox.js`：提供配置读取成功/失败结果，原保存接口不变。
- `frontend/widget-settings.js` / `mentor-strip.js`：焦点和可访问名称修正。
- `backend/app/application.py`：只对 `/assets` 静态资源启用已有 Starlette GZip；业务 API、下载和 AI 流不参与该压缩层。

没有引入前端运行时依赖。新增材质 CSS、导航动画和就地设置三个文件合计 gzip 约 6.8 KB。测试用 axe / Lighthouse 仅安装在被 Git 忽略的 `artifacts/ui-tools`，不进入产品。

### 性能与仍需观察的部分

Lighthouse 桌面测试使用隔离库。首轮新 UI 未压缩静态资源时观察到 LCP 约 3.5 秒；加入静态压缩后约 2 秒，总阻塞时间 0 ms。导师提醒占位后 CLS 从该轮 0.158 降到约 0.087。它们是当前机器的单次观察，不能作为低端安卓设备的帧率保证。最终原始报告见 `artifacts/material-lighthouse-preload.json`。

最终带模块预加载的报告：Performance **88**、Accessibility **97**、Best Practices **73**；LCP **2.0 s**、TBT **0 ms**、CLS **0.090**。整体页面尚未达到所有类别 90 分的目标，不标记为全面性能验收通过。

全页仍有既有问题：部分业务卡片可访问名称与可见长文案不完全对应、旧拖拽手柄偏小、部分动态内容仍有 CSP 报错，以及外部示例图片带来的第三方 Cookie 检查问题。新增面板的 axe 通过不代表整个历史页面已全部通过。这次没有放宽 CSP、修改第三方图片账户或改动已有缓存隐私策略来提高评分。

历史 `browser_theme.py` 和 `browser_pillars_probe.py` 分别仍引用已废弃的 `#today-view` 和“六个导航项”，本次不能用作通过证据。新探针覆盖现有七个主模块及宿主调色板；旧探针未被放宽断言来伪造验收。

## 使用更新

重新载入 Torch 工作台即可加载新前端资源。静态压缩这一后端优化在下次正常重启 Torch 服务后生效。没有自动重启正在使用的正式服务；没有安装或改包 Companion，也没有切换原数据库和同步引擎。


## 黄历可读性补充（2026-11-15）

针对实际 Obsidian 截图中的小字问题，黄历详情正文统一 16px、次级说明 14px，月历日期 17px / 农历 12px；农历标题 28px。干支和日期改横排，信息分区增加行距与留白，窄屏单列排列，不通过缩小字来塞进一屏。弹层只保留内容区滚动，标题与日期工具可持续访问。

选中节气日的农历文字跟随选中前景色，避免暗色背景上继续使用强调色；切换日期、月份后恢复对应控件焦点。“宜 / 忌”不再对读屏软件隐藏。工作台黄历卡片的摘要、签到按钮也适度放大。

验证截图与报告在 `artifacts/almanac-readability`。新增浏览器断言覆盖字号、横排、选中日颜色、重绘焦点、单滚动容器、320 / 390px 无溢出及黄历 axe 扫描；使用合成签到状态，没有执行用户真实签到。
