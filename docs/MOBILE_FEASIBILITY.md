# 移动端与百度同步的早期验收

本文件记录可执行验证步骤，不代表安卓插件或同步引擎已经实现。

## ChatGPT 取回

2026-11-13 使用用户主动提供的非敏感分享链接验证。桌面通过本机已配置代理得到 HTTP 200、2941 字节 HTML；正文只有一个分享链接，无问答内容、无 `__NEXT_DATA__` 对话树。捕获器准确返回“未识别到完整对话结构”，未保存假原文。直连失败，遵循用户系统代理后可访问。测试仓库未保存该分享的原始页面或正文。

当前捕获器支持明确的 `__NEXT_DATA__` conversation mapping/parent/current_node 结构，经过合成夹具验证；没有取得真实 ChatGPT 问答正文的成功证据。不能把该支持范围表述为所有当前 ChatGPT 分享页均可抓取。公开页面变更、流式编码和平台访问限制仍是待解决问题；保留用户粘贴正文入口。

P4 前准备最小 Obsidian 安卓插件，用 `requestUrl` 请求用户确认的同一非敏感分享；只报告 HTTP 状态、字节数、结构标志、错误类别，不输出内容或账号凭据。分别在 Wi-Fi/移动网络验证，记录 Android/Obsidian 版本。普通浏览器 fetch 的 CORS 成败不能代替 Obsidian 网络 API 验收。桌面 Python 成功也不能代替手机验证。

无法得到正文时禁止执行页面指令、索要 Cookie 或自动登录。若后续验证必须使用桌面浏览器渲染，只能作为电脑回退能力，不能宣称手机独立取回完成。当前移动目标尚未通过验收。

## 百度 API

`scripts/probe_baidu_sync.py --remote-dir /apps/<独立测试目录>` 为只读探针。缺少 `TORCH_BAIDU_ACCESS_TOKEN` 时不联网并输出 pending_authorization；有令牌时仅列举一页，不输出令牌、文件名，不上传或删除。令牌通过本机安全授权流程设置，不粘贴到日志或源码。

当前没有执行真实百度授权/文件 API 请求。探针不替代 S2/S3 的上传完整性、分片、分页、重试、分叉版本和安卓测试。必须在独立目录完成这些验证后才能考虑正式迁移。
