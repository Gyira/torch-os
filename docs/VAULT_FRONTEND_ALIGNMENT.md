## 缺失自动补建

- 真实、可写的个人实例启动时检查固定目录；运行中每 10 秒再次检查。
- 当前前端存在的固定本子、四库、生活系统、恋爱七页和固定恋爱本子缺失时原路径补建。
- 保留既有的“在前端主动删除内置本子”状态；不恢复已被明确从前端移除的本子。
- 自定义本子与用户清单名称仍由原有数据定义；不改名、不重新编号。
- 不覆盖现有文件；同名文件占位或目录链接导致修复失败时，保留它们并记录错误。
- 只读实例和注入测试库不启动巡检。巡检状态可从 `/api/config/status` 的 `data_layout` 读取。
- 自动补建仅恢复空目录结构，不是文件恢复功能。

## 迁移与回退

迁移脚本默认只预览。执行或回退前停止该库后端并关闭正在编辑的笔记；自动巡检运行期间不要离线回退。

```powershell
.\.venv\Scripts\python.exe scripts/align_vault_layout.py --vault "<资料库绝对路径>"
.\.venv\Scripts\python.exe scripts/align_vault_layout.py --vault "<资料库绝对路径>" --apply
.\.venv\Scripts\python.exe scripts/align_vault_layout.py --vault "<资料库绝对路径>" --rollback "<本批 manifest.json 绝对路径>"
```

只迁移显式映射的目录；拒绝越界、链接和目标冲突。变更前保存并校验原件和 SQLite 快照，文件移动逐个核对 SHA-256；清理只调用空目录删除。保留文档 ID 与记忆审核状态，仅更新结构化路径引用。Markdown/Wiki 链接复用仓库已有链接改写器，不改普通文字中的历史路径。

回退依据清单恢复目录与路径引用；发现迁移后的新编辑或引用变更会停止，避免覆盖新记忆。回退代码时必须一起恢复路径定义、启动巡检、恋爱共享路径和任务旧编号迁移逻辑，再恢复数据；保留本批回退脚本至数据恢复完成。其他资料库升级需显式执行迁移，不会在启动时擅自移动旧内容。
