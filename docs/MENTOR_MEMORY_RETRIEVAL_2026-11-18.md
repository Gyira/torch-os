# 人生导师：长期记忆与相关资料检索

这轮继续落实 AI 体验方案：让导师找得到较早的决定，区分用户原话和模型观察，尊重有明确对象的纠正。GPT 与 DeepSeek 使用同一套本地记忆和检索逻辑，切换模型不重建记忆。

## 使用体验

- 正常对话即可。例如“我决定保留工作，在职准备考研”，导师生成合格的记忆记录后，服务端保存能在本轮消息中核对的原话。保存数量或失败原因继续在对话界面反馈。
- 之后问“之前考研是怎么决定的”，读取记忆时会优先匹配问题，不再只读取最后 60 条时间线。较早的问答也按相关性选择。
- 如果说“之前的想法变了，我现在选择……”，导师可将纠正关联到本轮实际读到的旧记忆。旧记录保留在 Markdown 中，新记录明确指出取代对象；旧记录不再进入当前有效时间线。
- 问题仍使用旧观点的词语时，可以沿纠正关系找到新记录；不会为了关键词命中而重新注入已被取代的旧时间线正文。
- 自我档案优先排列相关本子和条目，提供条目 ID、路径、更新日期、证据及取代关系，便于正确引用与修正。
- 对话和“到 ChatGPT 继续聊”的资料准备都会使用当前问题检索。完整档案整理仍保留原有全量整理语义，不按整理任务的指令文字过滤资料。
- 记忆面板显示“用户原话”“模型观察 · 待核实”“旧记录 · 未校验原话”“已被纠正”，并展示来源。

## 记忆如何保证可追溯

仍使用 `01_自我档案/02_人生导师/记忆/` 下的 Markdown，没有迁移个人库、引入向量服务或上传索引。

### 来源与用户原话

`memory_notes` 增加 `evidence` 与 `supersedes`。

1. `evidence` 必须是本轮用户消息中逐字存在的 6–300 字片段。决定、目标变化、纠正没有合格原话时不写入，并返回可见错误。
2. 有合格原话时，保存原话本身，不能用模型改写替代；标注 `user_quote` 和会话来源。角色提示要求保留否定、条件与时间，不能把建议、假设或他人观点当用户决定。
3. 没有原话的观察必须引用本轮实际提供的来源编号；持久化时把 S/A 编号解析成资料来源，标注 `model_inference`，不会标成用户已确认事实。
4. 全量整理产生的时间线记录也标成模型观察，解析其本轮来源。旧记录仍可读取，但不追认成经过原话校验的事实。

精确匹配能证明文字出现过，不能证明模型正确理解了语义或引用范围。例如转述他人、反问、复杂条件仍可能被误判。因此界面保留原话和来源，模型观察明确待核实；本轮没有宣称实现全自动语义事实验证。

### 明确的纠正关系

时间线 ID 由记录日期、类型和正文计算，不依赖列表位置。新增状态信息放在行末 HTML 注释，普通 Markdown 阅读保持简洁。旧格式可以直接解析，无需重写整个库。

- 只有经过本轮用户原话校验的 `correction` 能关联旧记录。
- 目标必须在本轮导师记忆来源中实际包含；其他笔记中伪造的 `mem_...` 不能获得纠正权限。
- 写入前在原有文件锁内再次检查目标仍有效。读取后用户编辑了旧记录，或者另一轮已经纠正它，本轮不覆盖，返回错误。
- 支持连续纠正。原始正文保留；手动删除一条纠正记录后，读取时重新推导有效状态。
- 没有明确目标的纠正可保留为新的用户表述，不擅自寻找并覆盖意思相似的条目。

这不是跨文件的自动事实合并。核心摘要或另一份档案里若仍有旧说法，提示要求优先本轮明确纠正、揭示冲突；不会根据模糊相似性批量改写其他笔记。核心摘要仍可能需要下一次整理。

## 检索范围与成本

### 长期个人记忆

从已有时间线、问答与当前有效档案里做确定性的本地中文双字/英文词匹配。时间线最多选择 18 条相关记录，并补最多 6 条近期变化；问答最多选择 4 个相关块。遵守原有上下文字数预算，来源显示节选状态。

这能越过“最近记录”窗口，但不是语义向量检索。没有公共关键词的同义表达可能漏召回。未把全部历史聊天重新提炼为记忆，旧聊天里从未沉淀的决定不会凭空出现。

### 相关知识资料

原知识库“最近笔记”来源在有当前问题时，改为匹配知识库 Markdown 的标题和正文；不再排除 30 天以前的资料。摘录定位到词语集中的正文位置，最多返回 6 篇，并附真实路径和日期。

单轮最多检查 400 个合格 Markdown 文件、读取约 4 MB，每文件上限 256 KB。达到上限、文件无法解析时，来源元数据与上下文明确报告范围受限；没有匹配也不会声称整个库不存在资料。隐藏目录、系统目录、隐藏章节、已归档/被取代笔记不作为结果。

每次检索读取当前文件，因此删除或改写会在下次检索反映，不遗留持久化向量副本。沿用角色范围校验，先校验选择器，再读取允许的文件；学术导师不能通过这一入口读取自我档案，健康角色不能越界检索知识库。

不调用额外 AI、不产生嵌入费用、不访问外部网站。资料是参考，不因为进入上下文就代表用户认同其中观点。

## 验证与边界

- 隔离临时库测试：旧决定和旧问答召回、保存原话而非错误改写、拒绝无证据决定、模型观察标注、虚构来源拒绝、纠正链、并发编辑保护、伪造纠正标识拒绝、旧措辞召回新观点、跨角色边界、历史笔记正文摘录、删除文件、坏 YAML、隐藏目录和扫描上限。
- 原有主测试及角色、导师、记忆可靠性、档案操作回归：287 项通过、3 项跳过。后续来源绑定加固后的专项回归 86 项通过、2 项跳过，含 3 个新增用例；与前一轮存在重复覆盖，见 `artifacts/mentor-retrieval-final.log`。
- 前端 36 项通过；116 个模块的导入导出检查通过。记忆标签和来源的 HTML 转义有专项覆盖。
- 浏览器公共流程 76 项通过，无未捕获错误，报告：`artifacts/mentor-retrieval-browser/report.json`。该回归覆盖原有主界面、接力和设置流程，未将记忆标签单元测试冒充安卓真机验收。
- 没有调用真实 GPT/DeepSeek，没有改写真实个人资料，没有重启生产服务。实际回答质量、关键词召回质量和用户原话选择仍需要使用中的脱敏问题集评估。

下一步应依据真实漏召回案例改进分词/同义词和增量索引，而不是立即引入额外自动代理。长对话摘要、跨存储冲突合并、历史聊天补提炼仍需独立设计与验收。
