# UI 打磨第三批：AI 角色抽屉

日期：2026-11-02。保留 Enter 发送、Shift+Enter 换行、手动采纳提案、API 与后端数据格式。

## 诊断与改造

| 位置 | 原现象/用户影响 | 优先级 | 已实施 |
| --- | --- | --- | --- |
| 共用角色状态 | 关闭后的旧回复可能进入新角色并解除新请求忙碌状态 | P1 | 打开/关闭使用会话序号；旧成功、失败、finally 都不能写入当前会话 |
| 打开请求 | 网络返回后可能重新打开已关闭的角色 | P1 | 关闭使等待中的打开请求失效；编辑器宿主已关闭时不退回全局打开 |
| 输入框 | 失败丢失原文；快捷提问清空正在写的内容 | P1 | 失败仅在输入仍为空时恢复原文；快捷提问保留不同的草稿；后续输入优先 |
| 全局抽屉 | 遮罩之外仍可键盘进入背景 | P1 | 用原生 dialog 承载全局抽屉；原面板继续嵌入编辑器，沿用其焦点管理 |
| 阅读历史 | 每次刷新强制滚到底部、回复完成强制聚焦输入 | P2 | 距底部 64px 内跟随新回复，向上阅读保持位置；发送时滚到底部；回复不抢焦点 |
| 状态/焦点 | 空输入仍可提交；忙碌快捷按钮可重复点击；输入焦点较淡 | P1 | 空输入/忙碌禁用发送；忙碌禁用快捷按钮；aria-busy；2px 焦点环 |

## 行为、迁移与回退

| 原行为 → 新行为 | 理由与收益 | 成本/限制 | 回退 |
| --- | --- | --- | --- |
| 关闭丢草稿 → 页面内暂存 | 减少误关后的重写 | 按角色、模式、入口、文档/上下文隔离，最多 20 份；刷新清空。未保存的新文档没有稳定身份，不跨关闭暂存 | 撤销 roles.js 草稿 Map 和 note-editor.js 的 draftContext 接线 |
| 背景仍可键盘访问 → 全局原生模态 | 键盘范围与遮罩一致 | 打开时不能 Tab 到背景；编辑器内仍能操作正文 | index.html 的 modal 包裹、roles.js 宿主逻辑与 roles.css 配套撤销 |
| 回复到达强制焦点/滚动 → 保留阅读位置 | 不打断用户编辑和阅读 | 向上阅读时需自行滚到底部；不新增自动跳转 | 撤销对应渲染与聚焦片段 |

关闭仍结束当前可见会话，不取消已发到后端的请求；界面明确提示关闭后不再显示本轮回复。没有自动重试或自动重复扣费操作。发送超时仍沿用 180 秒。
切换文档/角色上下文清理旧可见对话，保留各自草稿，避免沿用旧文档的会话。

## 组件规格

| 状态 | 反馈 |
| --- | --- |
| 默认/空 | 原有角色说明与快捷问题；空白输入禁用发送 |
| hover/focus/active | 保留品牌悬停色；输入 2px 焦点环；快捷按钮按下使用填充色 |
| disabled/loading | 发送显示“思考中…”、aria-busy=true；快捷问题禁用；正文可继续输入 |
| error | 保留失败提示；原文可手动重试；新草稿不被覆盖 |
| success | 追加回复，恢复按钮；不自动采纳、不抢焦点 |

全局开启动效：220ms、16px 位移、cubic-bezier(.2,.8,.2,1)，继承全局 reduced-motion 禁用规则；发送按钮最小宽 88px。
粗指针下角色按钮至少 44×44px；沿用小屏底部面板与编辑器收起布局。本批不新增 RTL 支持或依赖。
