# Torch 多端测试与迁移操作手册

更新：2026-11-19。当前为功能集成开发版，正式切换尚未执行。本手册是验收步骤，不是已完成的验收记录。

## 安卓首次试用：先测本地功能

手机安装的是 **Torch Companion**（`torch-companion`），不是电脑上需要 Python 后端的 `torch` 工作台插件。它提供轻量首页，不会自动显示电脑端的完整任务、健康、恋爱和设置页面。

1. 在安卓 Obsidian 新建本地库 `Torch手机测试`，选择文件管理器可访问的内部存储位置。不需要下载整个个人数据库。
2. 将安装 ZIP 传到手机并解压。关闭 Obsidian，把里面的 `torch-companion` 文件夹放到 `Torch手机测试/.obsidian/plugins/torch-companion/`。看不到 `.obsidian` 时打开文件管理器的“显示隐藏文件”；`plugins` 不存在可创建。注意不要多套一层同名文件夹。
3. 确认该目录里直接有 `main.js`、`manifest.json`、`styles.css`。包里的说明和许可文件可一起保留，不复制其他设备的 `data.json` 或 `local`。
4. 重新打开测试库，在“设置 → 第三方插件”关闭受限模式，启用 **Torch Companion**。找不到时重启 Obsidian，检查目录和解压层级。最低 Obsidian 版本为 1.6.6。
5. 命令面板搜索 `Torch Companion`，执行“打开首页”。未配对提示是正常状态；本地功能不依赖百度授权。保持自动同步关闭。
6. 点“写今日日志”写一段文字，切换页面再打开；点“快速记录”保存一条。打开飞机模式继续编辑，关闭并重开应用，确认原文仍在。
7. 点“取回对话”，先把几段测试文字放入“正文兜底”，链接、轮次和仅回答留空。确认预览，再归档；检查知识库收件箱里的 Markdown。随后再联网测试公开分享链接；取回失败时使用正文粘贴。

本地写作和归档无需配对、无需电脑开机、无需填写模型 API Key。它保存用户提供或分享页取得的内容，不在手机上运行完整导师服务。两端同步另按下节授权配对，当前真实百度账号及安卓真机仍待验收。

## 使用方式

电脑原 Torch 工作台继续管理微信、媒体、滴答、业务数据库和现有 DSH；Companion 管理轻量笔记的百度同步。手机 Android Obsidian 打开 notes 库，插件提供日志、速记、对话取回和状态入口，也可以原生编辑 Markdown。

ChatGPT 继续用于日常聊天。选定笔记导出为最多四份主题 Markdown，自行上传到 ChatGPT 项目；对话有价值时复制公开分享链接，在手机取回、预览、确认归档。此流程不需要 GPT API，不替换 DSH。

## 独立测试库安装

1. 在百度桌面同步目录之外创建全新电脑/安卓测试库。只放合成笔记，不放私人日记。
2. 同一个库不启用上游百度同步、Obsidian Sync 或其他文件夹同步。百度桌面客户端以后只传输已完成的不可变备份包。
3. 将构建/ZIP 中整个 `torch-companion` 目录复制到两端 `.obsidian/plugins/`。应包含 main.js、manifest.json、styles.css、THIRD-PARTY-LICENSE.txt；不能复制另一端 data.json 或 local 目录。
4. 在 Obsidian 允许第三方插件并启用 Torch Companion，必要时重载。打开文件夹不会自动安装插件。
5. 首次安装、启用和配对后，日常打开相同库会加载插件。自动首页可关闭；恢复前台和后台同步不会抢当前编辑焦点。插件停用不影响原生 Markdown 编辑。

尚无运行中的安卓/Obsidian 测试环境，不能将代码构建成功当作真机通过。

## 百度授权与配对

真实百度应用权限、接口和安卓网络尚待验证。AppSecret、Token、同步密码只在本机填写，不发到聊天里。

1. 首台插件设置填 AppKey/AppSecret，专用应用目录 `/apps/实际应用名/torch-test-独立目录`。默认示例路径不代表你的应用已有权限。
2. 点“打开授权页”，完成百度登录，把授权码填入插件。凭据保存在设备插件配置，不参与本插件同步。
3. 设置至少 12 位同步口令，另外保管。默认仅留内存；选择“记住”会存入本机 data.json。
4. 点“初始化并配对”，只允许专用空命名空间。已有绑定、提交或其他文件不能重建；现有迁移库保留 UUID。不要两台设备同时初始化。
5. 中断后使用“验证并补全本机身份”，只核验既有远端，不重建或覆盖绑定。保留原配置与口令。
6. 首次上传前核对范围：四库 Markdown、笔记引用的小附件、受限收件/回执。用本机排除路径隐藏不需要上手机的文件。此名单与允许导出 ChatGPT 的选源独立。
7. 手动同步合成笔记。首台生成加密配对码，另设临时配对口令，在手机导入。手机生成新 device_id；不要复制电脑日志。先关闭自动同步，验证手机能解密、修改和传回。
8. 保存配对码及临时口令到私人恢复位置。配对码含加密后的同步口令与授权材料，按凭据保管。验证后关闭展示并清理临时剪贴板。
9. 完成验收矩阵再开启自动同步。修改防抖 3 秒、周期 60 秒、回前台检查，失败退避；不保证锁屏或系统杀进程后继续同步。

正文和提交用 AES-GCM 加密；百度仍可见目录、对象 SHA-256 名称、大小、数量和访问时间，也可能猜测已知内容的哈希。不承诺隐藏全部元数据。丢失全部解密材料不能恢复明文。

## 手机写作与直接归档

“写今日日志”按手机本地日期打开/创建 `人生路/日记/YYYY-MM-DD.md`；快速记录新建独立笔记。飞机模式下照常写作。“本地已保存”不等于其他设备已接收。

取回对话填写公开链接，可选轮次 `1,3-5`，仅回答填 yes。核对全文预览、标题和范围，再确认归档到知识库收件箱。原文保存不调用模型。未取回附件显示占位，必须明确接受只保存文本。

正文兜底直接粘贴已选内容，不抓网页、不推断角色/轮次，不要同时填写轮次/仅回答。超预算时缩小范围，不静默截断归档。预览已保存到本机插件日志，可从首页恢复；原始 HTML 不同步。

确认采用稳定内容指纹文件名，重复操作打开已有文件。两端独立导入后又各自编辑的副本不会按哈希删除，需保留核对。桌面台账可识别手机归档后补录，而不是再生成一次文章。

2026-11-15 电脑真实分享样例成功取得 23 轮、57,560 字符；匿名 JSON 回退是内部网页接口，可能改版，不是稳定 API。安卓必须用实际网络单独验证。

## 电脑回退收件

“交给电脑处理”只持久保存预览请求，明确等待同步和电脑。电脑下线不妨碍日志或手机直接归档。

权威电脑需已同步同一 notes，后端读取该目录，且只有这一台开启消费者。在启动对应后端的本机环境设置：

```powershell
$env:TORCH_QUEUE_AUTHORITY = '当前工作区 UUID'
```

重启对应后端使其生效；插件启动的进程应继承该环境，也可按既有后端命令启动。默认不消费，只读/QA 不启用。不要把同一配置交给第二台业务电脑。

手机 `_Torch/收件/<UUID>.md` → 同步到电脑 → 后端取得并保存快照 → `_Torch/回执/<UUID>.md` 同步回手机 → 用户核对预览并确认，生成新 share_commit 请求 → 后端使用同一快照归档 → 手机收到 archived 回执与普通笔记。回执先到、正文未到时提示等待。

预览不隐含归档授权；确认不重新抓网页。重复请求、发布回执前中断可恢复。取消用独立请求；已处理返回 too_late，不删已归档笔记。失败可重新建立预览或粘贴正文。不要修改旧请求、删除它来假装撤销。SQLite 锁只防同机重复进程，不是跨电脑租约；仅一台物理权威消费者。

## ChatGPT 资料包

桌面已有选源、预览、预算、变化提示和导出。手机每行填写明确相对 Markdown 路径，默认不选任何文件，只读取本机已取得资料。

核对全文后导出到 `_Torch/导出/<包 UUID>/`，此目录不参与同步。最多四份四库主题 Markdown，默认 2 MB 预算；疑似密钥阻止，未检出不代表已脱敏。附件不包含，外部链接不自动访问。

用户自行上传/替换 ChatGPT 项目文件。程序始终不假报上传成功；只提示上次选源是否变化，新笔记需重新选入。笔记同步不会自动更新项目背景。

## 冲突和附件

- 两端离线改同一篇：保留分叉，首页显示需处理。核对各版本，在编辑区确认合并正文；原分支留历史。
- 预览之后来了新版本：拒绝确认，重新审阅。
- 独立同名笔记：为其中一篇选择新相对路径。大小写冲突先在原生笔记中改成明显不同名称。
- 本机文件缺失先提示，不隐含远端删除，也不悄悄复活。明确确认才发布 tombstone；另一端需把本机原文移到恢复区确认。
- 取消同步范围不会删除。排除期间待上传意图保留并暂停，已上传历史不会因此擦除。
- 引用的 PNG/JPEG/WebP/GIF/AVIF/PDF 支持单附件 1 MiB、总预算 50 MiB。超限跳过/等待，文字照常保存，原件保留。新增笔记的附件可能要等 Obsidian 元数据索引更新后的下一轮同步。
- 已有二进制附件变更不自动覆盖；审阅中可把各版本另存 `_Torch/附件恢复/`，在原生 Obsidian 核对和更新链接。首版不做二进制合并，也没有自动安全清手机附件缓存。
- `_Torch/本机恢复/`、附件恢复和导出不参与同步。清理前核对是否有唯一内容。
- 当前云端可通过命令“导出云端可读恢复副本”写到新 `_Torch/恢复导出/`，不覆盖活动笔记，冲突分别保存。

## 不依赖 Obsidian 的离线恢复

从百度下载完整协议命名空间（binding、objects、commits），准备保存的配对码文本与临时口令。在电脑源码目录运行：

```powershell
.venv\Scripts\python.exe scripts\restore_companion.py D:\CloudCopy D:\Private\pair.txt D:\RecoveredNotes-New
```

口令交互输入，不放命令行参数。此工具不联网、不需要 Obsidian，验证绑定/提交/正文后写全新目录，分别保留冲突，不把授权材料放进可读笔记。密码错误、历史缺失、目标非空时失败。结果是派生副本，不能当成主动回滚全部云端的指令。

## 存储拆分与正式切换

五根：notes 是四库文本/必要附件/受限共享元数据；state 是主 DB、业务 DB、凭据、操作记录；archive 是主机媒体、原始文件、旧配置；cache 可重建；exports 放设备配置和导出物。五根不重叠，也不放进百度活动文件夹同步。

默认仍用 legacy。显式 `TORCH_STORAGE_CONFIG` 或桌面 Torch 插件“拆分存储配置”才启用 split。旧 `.torch-os/...` 逻辑名称映射到 state/vault-state，回收/恢复接口保持逻辑路径。身份缺失或错配时拒绝加载，不建另一份空库。

下列只是命令示例，需先确认权威 DB、全新目标和所有写入方停写窗口：

```powershell
.venv\Scripts\python.exe scripts\storage_tools.py prepare D:\OldVault --database D:\OldVault\.torch-os\torch_os.sqlite3 --target D:\Torch-Split-New --writers-stopped
```

只复制和校验，不切服务、不删除/移动原件。中断保留源与不完整目标，不能激活半成品。exports 中 MIGRATION.json/device-storage.json 包含逐文件哈希和引用审计。旧 Obsidian 配置保留 archive/legacy-vault，防止新库自动启动旧插件/旧后端；需重新安装并明确绑定。

未确认引用、Canvas/复杂链接、业务 DB 绝对路径、历史冲突库独有记录、库外 DSH 会话仍须按实际报告核对。库外 DSH 工作区/环境配置另做备份，不能声称五根包包含所有外部会话。

准备副本后做多根备份与全新目录恢复：

```powershell
.venv\Scripts\python.exe scripts\storage_tools.py backup D:\Torch-Split-New\exports\device-storage.json D:\CompletedBackups\torch-test.enc
.venv\Scripts\python.exe scripts\storage_tools.py restore D:\CompletedBackups\torch-test.enc D:\Restore-Drill-New
```

包包含 notes/state/archive（含恢复所需本机配置），不含 cache；exports 的资料包可由原文重建。备份口令兼容原功能至少 8 位，建议更长，与同步口令分开。SQLite 使用在线备份，但跨 DB/正文一致性仍需要停写窗口。恢复检查全文件哈希和 integrity_check，只写新目录，不激活。

正式切换顺序：原库清点及独立备份 → 百度/安卓测试库验收 → 停写 → copy-only 准备 → 引用/独有记录/库外 DSH 核对 → 多根备份恢复 → 桌面业务回归 → 停旧后端和旧文件夹同步 → 桌面插件绑定新 notes 与本机 storage JSON → 首轮同步并核对手机 → 再启唯一业务消费者。

本次尚未执行正式切换，原目录仍在用。切换后回退要先停写、保存新笔记和冲突、回收增量，再恢复旧布局，不能直接打开旧目录丢掉新稿。

## 更新、停用和边界

更新前确认编辑已同步，另备份本机 data.json/local 和旧安装包。只替换构建包文件，不覆盖本机配置，先测试再更第二端。停止自动同步并等当前任务结束后可禁用插件，Markdown 继续使用。

首版不自动清云端历史或本机日志；达到 10,000 提交扫描预算时停止，不能手工删祖先。元数据冷启动完整扫描，尚需真实网络性能记录。未知协议拒绝继续，协议升级须迁移，不能盲目用旧插件覆盖新版继续写。

当前没有自动口令轮换/设备密钥撤销；材料泄漏时停止同步，在新命名空间重新加密配对，并保留旧副本核对。Obsidian SDK 不提供可控重定向/底层取消，本机超时不保证请求已取消；输入 URL 固定公开来源白名单，真实平台网络行为需要验收，不冒称完成全部网络安全矩阵。
